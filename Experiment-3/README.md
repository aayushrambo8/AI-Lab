# Experiment 3: Utility-Based Agent

- **File:** `UtilityBasedAgent.py`
- **Description:** A utility-based agent in a 2D grid environment built from user input. The grid is populated with obstacles (`X`), rewards (`R`) and penalties (`P`). Starting from a given position, the agent moves towards the goal, steps around obstacles when its preferred move is blocked, and reports the rewards collected and penalties tackled along the way. Visited cells are marked with `=` and the grid is printed after every move.
